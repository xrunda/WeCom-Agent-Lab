# 证据归档

本目录用于存放 M1 每项结论的证据索引。原始截图/日志放 `evidence/raw/`（已 gitignore）。

## 命名规范

```
raw/
  M1-02_外部群添加机器人_无入口.png
  M1-02_控制台智能机器人_使用范围说明.png
  M1-06_群发助手_成员确认界面.png
  M1-08_会话存档_后台开通页.png
  M1-03_存档拉取_脱敏日志.txt
```

格式：`<测试编号>_<场景>_<序号>.<扩展名>`

## 每张证据必须同时记录

| 字段 | 说明 |
|---|---|
| 测试编号 | M1-XX |
| 采集时间 | YYYY-MM-DD HH:mm |
| 采集人 | |
| 环境 | 企微版本 / 客户端类型（Win/Mac/iOS/Android）/ 群类型 |
| 说明 | 这张图证明了什么 |
| 脱敏 | 是否已遮挡客户昵称、手机号、头像、二维码 |

## 禁止

- 不提交真实客户资料、真实聊天正文、密钥、二维码、企业完整名称。
- 截图前先做脱敏；无法脱敏的只记录观察结论，不存原图。

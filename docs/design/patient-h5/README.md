## 使用规则

整页参考图中的文字、日期、图标、按钮、卡片和导航用真实组件实现，不能整页作为背景图上线。图片上的经典引文可能存在生成误差，正式文本按审核稿排版。

正式素材在页面布局确定后独立生成或取得授权，保留干净原图，再按实际容器裁剪和压缩。照片、插画、头像与真实用户上传图片分开管理。

本次原样归档，不裁剪、不压缩、不重新生成图片。图中的人物、团队及健康数据为概念示例；头像不作为真实专业人员身份凭证。

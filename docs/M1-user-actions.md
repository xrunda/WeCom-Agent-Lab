# 需要你配合的事项

> 我只做本地能完成的部分（文档、代码、脚本、分析）。以下是**只有你/你的企微管理员能做**的操作。
> 按优先级排序。做完一项把截图或结果发我，我更新矩阵与报告。

---

## 🔴 P0：决定 M1 是否继续（约 1 小时）

### 1. 确认基础信息

请告诉我：

- [ ] 企微主体是否已认证？
- [ ] 大致套餐/版本（免费版 / 专业版 / 有客户联系权限？）
- [ ] 你是否是超级管理员？（不是的话，谁能操作）
- [ ] 管理后台有没有「智能机器人」入口？
- [ ] 管理后台有没有「会话内容存档」入口？显示什么状态？

### 2. 创建测试外部客户群（关键）

- [ ] 用内部员工号拉 2 个**测试微信小号**建群
- [ ] 截图群设置页，确认群类型显示为「外部群」/「客户群」
- [ ] 再建一个同样结构的 B 群

### 3. 做 M1-02 决定项（最重要）

在外部群里：

- [ ] PC 端：群聊 → 右上角「+」/群成员 → 找「智能机器人」，截图
- [ ] 手机端：同样操作，截图
- [ ] 群设置里找「消息推送 / 群机器人」，截图
- [ ] 作为对照：在内部群做同样操作，截图

**预期是前三个都没有入口**（官方文档已写明外部群不支持）。如果确实没有，M1 的方向就要调整；如果有，请立刻告诉我，这是重大发现。

## 🟠 P1：读路径（需要管理员，约半天 + 审核等待）

### 4. 会话存档

- [ ] 后台 → 管理工具 → 会话内容存档，截图价格与版本
- [ ] 确认能否申请 30 天免费试用
- [ ] 若可试用：提交申请（可能需要盖章确认函）
- [ ] 告诉我：真实单价、最小席位、审核时间

### 5. 如果开通了，给我这些（**不要发在聊天里**）

- [ ] CorpID
- [ ] 会话存档 Secret
- [ ] RSA 私钥文件
- [ ] 官方 SDK（Linux .so 或 Windows .dll）

请放到 `.env.local` 和 `config/`（已在 gitignore），不要贴聊天、不要截图。

## 🟢 P3：只需回答的问题

1. 如果确认外部群不能加 AI 机器人，你倾向哪条路？
   - A. 接受「存档读取 + 小助理/群发」的平台能力上限
   - B. 改成「机器人单聊」或「内部群机器人 + 人工转发」（仅作替代架构，不算 M1 通过）

2. 是否允许我为这次实测申请会话存档试用？
3. 有没有必须遵守的合规/法务要求（告知文本、数据留存期限）？
